# NLP Extractive Summarization

A coursework project focused on **Natural Language Processing (NLP)** and extractive text summarization using **NLTK** and **spaCy**.

## 📌 Project Overview

The goal of this project is to create an extractive text summarization approach that identifies the most important sentences in a text.

The text is processed using NLTK and spaCy. Word frequencies are calculated for meaningful words, and each sentence receives a score based on those frequencies. The highest-scoring sentences are selected for the final summary while preserving their original order.

## 🛠 Technologies

- Python
- NLTK
- spaCy
- Natural Language Processing

## 🔍 Approach

1. Process and tokenize the input text
2. Filter meaningful words
3. Calculate word frequencies
4. Assign scores to sentences
5. Select the highest-scoring sentences
6. Preserve the original sentence order in the final summary
